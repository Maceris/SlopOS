# Decisions

One short file per decision, numbered in the order they're made: `0001-microkernel.md`,
`0002-capability-model.md`, and so on. Never edit a decided record to change its meaning;
write a new one that supersedes it, so the history of *why* survives.

## Template

```markdown
# NNNN: Title

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context
What problem forced a decision, and what constraints apply.

## Decision
What we're doing.

## Alternatives considered
What else was on the table and why it lost.

## Consequences
What this makes easier, what it makes harder, what it commits us to.
```
