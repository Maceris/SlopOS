# Project

This project is a micro-kernel / Operating System written in Hemera.
Whether or not this entire project is a joke depends entirely on if you think it is funny.

# Structure

* `knowledge` - Planning and project memory: ideas, open questions, decisions, design notes, conventions, Hemera feedback
* `docs` - Official user and developer documentation: specifications, API documentation, architecture diagrams
* `CLAUDE.md` - Summary of goals and rules for working on the project
* `src` - Project source code

SlopOS uses Hemera's own standard library, and general-purpose code it needs is written there.
